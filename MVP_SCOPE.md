# MVP Scope — DebugMate & CodeDNA

## Overview
DebugMate (CodeDNA) is a beginner-friendly programming practice platform focused on learning to **debug**, rather than copying pre-generated AI solutions.

---

## In Scope for MVP
1. **Frontend Experience (Skilotech-Inspired)**:
   - Floating glass island navigation bar with live operational probe indicator.
   - Dual theme support (Midnight Cyber Dark & Studio Canvas Light).
   - High-impact hero section with typographic watermark and simulated macOS code editor.
   - Interactive 4-stage pedagogical journey.
   - Infinite tech stack marquee with gradient edge masks.
   - Interactive Browser Showcase with multi-tab telemetry, CRUD manager, and Docker topology.
   - Responsive design tested on mobile, tablet, and widescreen.

2. **CodeDNA Debugging Mission Sandbox**:
   - Curated debugging missions (Off-by-One Array Bounds, Null Pointer Guards, String Palindromes).
   - Java 21 & JavaScript ES2024 parity.
   - "Explain Before You Fix" cognitive hypothesis gate.
   - 3-tier progressive hint ladder (Concept -> Location -> Logic Blueprint).
   - Safe test evaluation: public tests + obfuscated hidden edge-case tests.
   - Bug Fingerprint profiling & mistake pattern tracking.

3. **Backend REST API**:
   - `/api/health` system telemetry with memory heap metrics and Docker probe.
   - `/api/info` hardware specifications and platform architecture.
   - `/api/items` in-memory CRUD operations for sprint items.

4. **Containerization & DevOps**:
   - Multi-stage Nginx production build for frontend.
   - Lightweight Alpine Linux Node 20 backend with non-root security.
   - Docker Compose bridge network (`hackathon-network`) with automated health checks.

---

## Out of Scope for MVP (Future Roadmap)
- Learner multi-tenant authentication (e.g. Clerk/OAuth integration in production).
- Persistent PostgreSQL/Redis database tier.
- Distributed sandbox cluster running arbitrary untrusted bytecode with Docker-out-of-Docker.
