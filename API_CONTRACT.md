API contract (frontend/backend agreement)
Keep this file aligned with server/src/routes. Coordinate contract changes before merging frontend/backend work.
General rules
- Base path: /api.
- JSON request/response bodies.
- Supported language IDs: javascript, java.
- Set request body limit; validate all fields and reject unknown challenge IDs.
- Responses must not include hidden test input, expected output, source code, or private grading logic.
GET /api/health
200 OK
{ "status": "ok", "service": "codedna-api" }
GET /api/challenges
200 OK
{
  "challenges": [
    {
      "id": "largest-number",
      "title": "Find the largest number",
      "difficulty": "easy",
      "concept": "loop_boundary",
      "languages": ["javascript", "java"]
    }
  ]
}
Do not include hidden test cases in this response.
GET /api/challenges/:id
200 OK
{
  "challenge": {
    "id": "largest-number",
    "title": "Find the largest number",
    "difficulty": "easy",
    "concept": "loop_boundary",
    "description": "Debug the program so it prints the largest integer in the input array.",
    "languages": ["javascript", "java"],
    "starterCode": {
      "javascript": "...",
      "java": "..."
    },
    "visibleTests": [
      { "id": "visible-1", "stdin": "4\\n2 5 1 9\\n", "expectedStdout": "9\\n" }
    ]
  }
}
404 Not Found for unknown challenge IDs. Visible tests may include inputs and expected output; hidden tests may not.
POST /api/submissions
Request:
{
  "challengeId": "largest-number",
  "language": "javascript",
  "code": "... learner source code ...",
  "prediction": "The loop visits all array elements.",
  "explanation": "I think the loop ends after the last index."
}
On a configured safe runner, 200 OK response shape:
{
  "submissionId": "server-generated-id",
  "status": "failed",
  "results": [
    { "testId": "visible-1", "visibility": "visible", "status": "wrong_output", "expected": "9\\n", "actual": "5\\n" },
    { "testId": "hidden-1", "visibility": "hidden", "status": "passed" }
  ],
  "feedback": {
    "summary": "The loop may be stopping before it visits every element.",
    "bugCategory": "loop_boundary",
    "hintLevelAvailable": 1
  }
}
Allowed test statuses: passed, wrong_output, runtime_error, timeout; additionally compile_error is allowed for languages that compile before running.
Hidden result objects may contain only an opaque test ID, visibility: "hidden", and status. Do not include hidden expected/actual output or input. A submissionId should be generated by the server, not trusted from the browser.
Before runner integration, this endpoint returns 503 Service Unavailable:
{
  "error": {
    "code": "RUNNER_NOT_CONFIGURED",
    "message": "Code execution is not configured. The submission was not executed."
  }
}
Validation errors use 400; unknown challenge IDs use 404; rate limiting uses 429; unexpected errors use 500 without leaking secrets or private test data.
